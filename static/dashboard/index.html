Configuración del proxy
Ajustes del proxy

Configura un proxy HTTP/HTTPS o SOCKS5 para las conexiones de WhatsApp. Opcionalmente, los webhooks pueden salir por el mismo proxy o ir directo a tu backend.

Activa o desactiva el proxy de esta instancia.
Incluye el protocolo (http://, https:// o socks5://) y el puerto. La autenticación puede ir en la URL.
Si está activo, los POST de webhook salen por el proxy configurado. Desactívalo para llegar directo a tu backend mientras WhatsApp sigue usando el proxy.
Configuración HMAC
Ajustes de la clave HMAC

Configura la clave HMAC para la seguridad del webhook. Sirve para verificar que el webhook es auténtico.

Aviso de seguridad importante

Por seguridad, la clave HMAC se oculta después de guardarla.
• No podrás volver a verla
• Guarda una copia en un lugar seguro antes de continuar
• Si la pierdes, tendrás que generar una nueva

Mínimo 32 caracteres por seguridad. Mantén esta clave en secreto.
Envío pausado
Enviar en lotes con pausas

Si está activo, cada envío se pone en cola (HTTP 202) y sale en lotes pequeños con pausas aleatorias y un tope por hora. Reduce el riesgo de que WhatsApp marque el número, pero no lo elimina.
