WhatsApp para tus sistemas, con una llamada HTTP

WspBox es una API REST para enviar y recibir mensajes de WhatsApp desde tu aplicación. Varias sesiones en una misma instalación, sin emuladores ni navegadores.

Abrir el panel Probar el cliente web

Lo que incluye

Una API completa para WhatsApp que habla directo con sus servidores, sin Puppeteer ni emuladores de Android.

Rápida y liviana

Se conecta por websocket directamente a WhatsApp, con poco uso de memoria y de procesador.

Varias sesiones

Atiende varios teléfonos y usuarios a la vez en la misma instalación.

Todo tipo de mensajes

Envía texto, imágenes, audio, documentos, video, stickers, ubicaciones y contactos.

Webhooks

Recibe en tu sistema los mensajes y eventos de WhatsApp en cuanto ocurren.

Verificación de números

Comprueba si un número tiene WhatsApp y consulta los datos de su perfil.

Acceso por token

Cada usuario trabaja con su propio token, sin contraseñas que compartir.

Cómo empezar

Paso 1

Entra al panel

Ingresa con el token de tu usuario. Si todavía no tienes uno, pídeselo a quien administra WspBox.

Paso 2

Vincula el teléfono

Escanea el código QR desde WhatsApp, en Dispositivos vinculados.

Paso 3

Envía y recibe mensajes

Usa la API con tu token o configura un webhook para recibir los eventos.

Conecta tu primer número

Entra al panel con tu token y escanea el código QR.
